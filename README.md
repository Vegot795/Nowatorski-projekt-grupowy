# Nowatorski projekt grupowy

Nazwa gry: Magic Garden

Autorzy:
- Davies Ogunruku
- Aleksandra Klimuk
- Paweł Nizio

Przebieg gry:
Celem gracza jest rozwijać swój ogród, jednocześnie broniąc go przed przeciwnikami. Gracz może sadzić wiele rodzajów nasion, aby uzyskać plony za które dostaje dodatkowe nasiona do sadzenia oraz walutę umożliwiającą rozwój postaci (więcej pól uprawnych, zwiększone obrażenia, zwiększony poziom zdrowia, ETC)

Systemy:
- Ekwipunek
- Walka
- AI botów + system spawnowania
- Sadzenie nowych roślin wraz z podglądem na bierząco
- Budowa/niszczenie pól uprawnych wraz z podglądem na bierząco
- Sklep
- System zdrowia / regeneracji postaci
- UI
